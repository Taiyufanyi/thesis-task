# 论文写作打卡

论文写作打卡网站，涵盖第五章研究结果 → 第六章讨论 → 结论 → 缓冲整合（2026.11.2 – 2027.1.15）。

## 功能
- 右上角显示每章倒计时，截止时间可以修改，倒计时自动更新
- 每个任务可以计时，复盘页查看每天每个任务的用时
- 每天的标题和任务自己填写（点标题旁的 ✎，或双击标题），内容只存在自己的浏览器里
- 每天可记录心情、字数、灵感、问题/改进和明日调整
- 小论文修改单独统计用时
- 导出 / 导入备份（JSON）

## 数据说明
记录保存在当前浏览器（localStorage），不会上传到 GitHub。
换电脑、换浏览器或清理浏览器缓存之前，先点页面底部的「导出备份」。

## 部署
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
